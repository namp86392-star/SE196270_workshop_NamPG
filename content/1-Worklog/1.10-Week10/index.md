# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 10 – Learning about AWS WAF and Web Application Security on AWS

### Monday – Introduction to AWS WAF

**Activities Performed:**
- Learned about the concept and role of AWS Web Application Firewall (AWS WAF).
- Studied how AWS WAF protects web applications against unwanted access requests.
- Explored AWS services that can be integrated with AWS WAF.
- Studied the role of Web Application Firewalls in web application security.

**Results Achieved:**

Understood the functions of AWS WAF and its role in monitoring and controlling access requests to web applications.

### Tuesday – Learning about Web ACLs and Rules in AWS WAF

**Activities Performed:**
- Learned about the concept of Web Access Control Lists (Web ACLs).
- Studied how to create and configure Rules in AWS WAF.
- Explored request handling actions such as Allow, Block, and Count.
- Studied how Rules are used to identify and control web traffic.

**Results Achieved:**

Understood the basic structure of Web ACLs and how Rules can be used to control access requests to web applications.

### Wednesday – Learning about Web Application Protection Mechanisms

**Activities Performed:**
- Learned how AWS WAF helps detect and block unwanted HTTP/HTTPS requests.
- Studied the Managed Rules provided by AWS WAF.
- Explored the role of Rate-based Rules in controlling request frequency.
- Studied how AWS WAF helps reduce common security risks affecting web applications.

**Results Achieved:**

Understood how AWS WAF uses Rules to filter traffic and help protect web applications against potentially abnormal requests.

### Thursday – Practicing and Reviewing AWS WAF

**Activities Performed:**
- Explored and practiced configuring AWS WAF based on the lab materials.
- Observed how Web ACLs apply Rules to process access requests.
- Learned how to monitor the activities and results of Rule evaluations.
- Reviewed the knowledge gained about AWS WAF and web application security measures.

**Results Achieved:**

Strengthened knowledge of AWS WAF, understood how to configure access control rules, and learned the role of Web Application Firewalls in improving web application security.
