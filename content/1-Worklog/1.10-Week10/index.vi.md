# BÁO CÁO TIẾN ĐỘ HỌC TẬP

**Lĩnh vực: AWS Cloud Security**

## TUẦN 10 – Tìm hiểu AWS WAF và bảo mật ứng dụng web trên AWS

### Thứ 2 – Tìm hiểu tổng quan về AWS WAF

**Nội dung thực hiện:**
- Tìm hiểu khái niệm và vai trò của AWS Web Application Firewall (AWS WAF).
- Nghiên cứu cách AWS WAF bảo vệ các ứng dụng web trước những yêu cầu truy cập không mong muốn.
- Tìm hiểu các dịch vụ AWS có thể tích hợp với AWS WAF.
- Nghiên cứu vai trò của Web Application Firewall trong bảo mật ứng dụng web.

**Kết quả đạt được:**

Hiểu được chức năng của AWS WAF và vai trò của dịch vụ này trong việc giám sát, kiểm soát các yêu cầu truy cập đến ứng dụng web.

### Thứ 3 – Tìm hiểu Web ACL và Rule trong AWS WAF

**Nội dung thực hiện:**
- Tìm hiểu khái niệm Web Access Control List (Web ACL).
- Nghiên cứu cách tạo và cấu hình các Rule trong AWS WAF.
- Tìm hiểu các hành động xử lý yêu cầu như Allow, Block và Count.
- Nghiên cứu cách các Rule được sử dụng để xác định và kiểm soát lưu lượng truy cập web.

**Kết quả đạt được:**

Nắm được cấu trúc cơ bản của Web ACL và cách sử dụng các Rule để kiểm soát những yêu cầu truy cập đến ứng dụng web.

### Thứ 4 – Tìm hiểu các cơ chế bảo vệ ứng dụng web

**Nội dung thực hiện:**
- Tìm hiểu cách AWS WAF hỗ trợ phát hiện và ngăn chặn các yêu cầu HTTP/HTTPS không mong muốn.
- Nghiên cứu các Managed Rules được AWS WAF cung cấp.
- Tìm hiểu vai trò của Rate-based Rules trong việc kiểm soát tần suất truy cập.
- Nghiên cứu cách AWS WAF hỗ trợ giảm thiểu một số rủi ro bảo mật phổ biến đối với ứng dụng web.

**Kết quả đạt được:**

Hiểu được cách AWS WAF sử dụng các Rule để lọc lưu lượng truy cập và hỗ trợ bảo vệ ứng dụng web trước những yêu cầu có dấu hiệu bất thường.

### Thứ 5 – Thực hành và tổng kết về AWS WAF

**Nội dung thực hiện:**
- Tìm hiểu và thực hành cấu hình AWS WAF theo nội dung bài lab.
- Quan sát cách Web ACL áp dụng các Rule để xử lý yêu cầu truy cập.
- Tìm hiểu cách theo dõi hoạt động và kết quả xử lý của các Rule.
- Tổng hợp kiến thức về AWS WAF và các biện pháp bảo mật ứng dụng web.

**Kết quả đạt được:**

Củng cố kiến thức về AWS WAF, hiểu được cách thiết lập các quy tắc kiểm soát truy cập và vai trò của Web Application Firewall trong việc tăng cường bảo mật cho ứng dụng web.
