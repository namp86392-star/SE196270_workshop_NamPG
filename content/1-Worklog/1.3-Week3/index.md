# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 3 – Learning about VPC and Network Security on AWS

### Monday – Introduction to Amazon VPC

**Activities Performed:**
- Learned about the concept and role of Amazon Virtual Private Cloud (VPC).
- Studied how VPC provides an isolated network environment for AWS resources.
- Explored the basic components of VPC, including CIDR, Subnet, and Route Table.

**Results Achieved:**

Understood the role of VPC in building and managing network environments on AWS, as well as the basic components of a VPC.

### Tuesday – Learning about Subnets and Network Routing

**Activities Performed:**
- Learned the differences between Public Subnets and Private Subnets.
- Studied the functions of Internet Gateway and NAT Gateway.
- Explored how Route Tables direct network traffic between components.
- Studied how to organize networks to separate resources based on access requirements.

**Results Achieved:**

Understood how to divide networks into Public and Private Subnets and learned the role of routing components in controlling network connectivity.

### Wednesday – Learning about Network Security Mechanisms

**Activities Performed:**
- Learned about Security Groups and Network Access Control Lists (Network ACLs).
- Studied the differences between Security Groups and Network ACLs.
- Explored how to control inbound and outbound traffic for AWS resources.
- Studied the role of access control mechanisms in protecting network infrastructure.

**Results Achieved:**

Understood the basic network security mechanisms in AWS and how Security Groups and Network ACLs can be used to control network traffic.

### Thursday – Practicing and Reviewing Amazon VPC

**Activities Performed:**
- Practiced exploring and configuring the basic components of Amazon VPC.
- Observed the relationships between VPC, Subnets, and Route Tables.
- Learned how to configure network access control rules.
- Reviewed the knowledge gained about network architecture and security mechanisms on AWS.

**Results Achieved:**

Strengthened knowledge of AWS network architecture, understood how VPC components work together, and learned the importance of network security in protecting cloud resources.
