
# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 11 – Learning about AWS KMS and Encryption Key Management on AWS

### Monday – Introduction to AWS KMS

**Activities Performed:**
- Learned about the concept and role of AWS Key Management Service (AWS KMS).
- Studied how AWS KMS supports the creation and management of encryption keys.
- Explored the role of encryption in protecting data in cloud environments.
- Studied common use cases of AWS KMS within the AWS ecosystem.

**Results Achieved:**

Understood the functions of AWS KMS and its role in managing encryption keys and helping protect data on AWS.

### Tuesday – Learning about Different Types of Keys in AWS KMS

**Activities Performed:**
- Learned about Customer Managed Keys and AWS Managed Keys.
- Studied the differences between keys managed by AWS and those managed by customers.
- Explored the lifecycle of encryption keys in AWS KMS.
- Studied the available options for creating and managing encryption keys.

**Results Achieved:**

Understood the different types of encryption keys in AWS KMS and the differences in management responsibilities and control between them.

### Wednesday – Learning about Security and Access Control in AWS KMS

**Activities Performed:**
- Learned how to manage key usage permissions through Key Policies.
- Studied the relationship between AWS KMS and IAM in access control.
- Explored basic permissions related to the use and management of encryption keys.
- Studied the importance of access control in protecting encryption keys.

**Results Achieved:**

Understood how AWS KMS uses Key Policies and IAM to control access permissions and recognized the importance of protecting encryption keys.

### Thursday – Practicing and Reviewing AWS KMS

**Activities Performed:**
- Explored and practiced the basic functions of AWS KMS based on the lab materials.
- Observed the process of creating and managing encryption keys.
- Learned how to configure access permissions for keys.
- Reviewed the knowledge gained about data encryption and key management on AWS.

**Results Achieved:**

Strengthened knowledge of AWS KMS, understood how to manage encryption keys, and learned the role of this service in improving data security in cloud environments.
