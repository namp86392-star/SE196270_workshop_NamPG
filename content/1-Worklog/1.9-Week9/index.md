# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 9 – Learning about IAM Permission Boundaries and Advanced Access Control on AWS

### Monday – Introduction to IAM Permission Boundaries

**Activities Performed:**
- Learned about the concept and role of IAM Permission Boundaries.
- Studied how Permission Boundaries limit the maximum permissions that can be granted to IAM Users or IAM Roles.
- Explored the differences between standard IAM Policies and Permission Boundaries.
- Studied the role of Permission Boundaries in AWS access management.

**Results Achieved:**

Understood the functions of IAM Permission Boundaries and how this mechanism limits the maximum access permissions of IAM Users and IAM Roles.

### Tuesday – Learning about How Permission Boundaries Work

**Activities Performed:**
- Studied how Permission Boundaries work together with Identity-based Policies to determine effective permissions.
- Explored the relationship between granted permissions and maximum permission limits.
- Studied cases where access is denied because it exceeds the scope of a Permission Boundary.
- Learned how Permission Boundaries can be used to manage user access permissions.

**Results Achieved:**

Understood the operating principles of Permission Boundaries and learned that effective permissions must fall within the limits allowed by both the granting policy and the Permission Boundary.

### Wednesday – Exploring Permission Boundaries in Security Management

**Activities Performed:**
- Learned how to use Permission Boundaries to restrict the permissions of IAM Users and IAM Roles.
- Studied the role of Permission Boundaries in preventing permissions from exceeding authorized limits.
- Explored how Permission Boundaries work together with the Least Privilege principle.
- Studied practical use cases of Permission Boundaries in AWS environments.

**Results Achieved:**

Understood how Permission Boundaries support access control and reduce risks caused by excessive permissions in AWS environments.

### Thursday – Practicing and Reviewing IAM Permission Boundaries

**Activities Performed:**
- Explored and practiced configuring IAM Permission Boundaries based on the lab materials.
- Observed changes in access permissions after applying a Permission Boundary.
- Examined the relationship between Identity-based Policies and Permission Boundaries.
- Reviewed the knowledge gained about access management and security control mechanisms in IAM.

**Results Achieved:**

Strengthened knowledge of IAM Permission Boundaries, understood how permission limits can be applied to identity management, and improved understanding of access control on AWS.
