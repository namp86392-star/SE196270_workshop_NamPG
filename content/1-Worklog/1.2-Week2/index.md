# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 2 – Learning about IAM and Access Management on AWS

### Monday – Introduction to AWS IAM

**Activities Performed:**
- Learned about the concept and role of AWS Identity and Access Management (IAM).
- Studied how IAM manages identities and access permissions to AWS resources.
- Explored the basic components: IAM User, Group, Role, and Policy.

**Results Achieved:**

Understood the functions of IAM and its role in managing access permissions and protecting resources on AWS.

### Tuesday – Learning about IAM Policy and Access Control

**Activities Performed:**
- Studied the structure and operation of IAM Policies.
- Learned the differences between Allow and Deny permissions.
- Explored how to assign Policies to Users, Groups, and Roles.
- Studied the Least Privilege principle.

**Results Achieved:**

Understood the access control mechanism in AWS IAM and the importance of granting appropriate permissions to minimize security risks.

### Wednesday – Practicing IAM User and Group Management

**Activities Performed:**
- Practiced creating IAM Users and IAM Groups.
- Configured access permissions by assigning Policies.
- Learned how to manage and check users' access permissions.
- Observed the differences in permissions between IAM accounts.

**Results Achieved:**

Gained the ability to perform basic user and group management tasks in AWS IAM and understood how to assign access permissions to different entities.

### Thursday – Learning about IAM Role and Weekly Summary

**Activities Performed:**
- Learned about IAM Roles and their purposes in AWS.
- Studied the differences between IAM Users and IAM Roles.
- Explored how IAM Roles provide access permissions between AWS services.
- Reviewed the knowledge gained about IAM and related security principles.

**Results Achieved:**

Understood how to use IAM Roles to manage access permissions between AWS services and strengthened knowledge of identity management and access control.
