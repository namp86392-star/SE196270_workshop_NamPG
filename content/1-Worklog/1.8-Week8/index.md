# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 8 – Learning about AWS CLI and Managing AWS Resources through Command Line

### Monday – Introduction to AWS CLI

**Activities Performed:**
- Learned about the concept and role of AWS Command Line Interface (AWS CLI).
- Studied how AWS CLI supports interaction with AWS services through command-line commands.
- Explored the differences between managing resources through AWS Management Console and AWS CLI.
- Studied common use cases of AWS CLI.

**Results Achieved:**

Understood the functions of AWS CLI and its role in supporting the management and interaction with AWS services through command-line commands.

### Tuesday – Learning how to Use AWS CLI

**Activities Performed:**
- Learned about the basic structure of an AWS CLI command.
- Studied how to use commands to retrieve information about AWS services.
- Explored commonly used command parameters and options.
- Practiced basic commands to become familiar with AWS CLI.

**Results Achieved:**

Understood the basic structure of AWS CLI commands and learned how to use them to interact with and retrieve information from AWS services.

### Wednesday – Exploring AWS CLI in Resource Management

**Activities Performed:**
- Learned how to use AWS CLI to manage and inspect AWS resources.
- Studied how to retrieve information about services such as EC2 and S3.
- Explored how AWS CLI can support the automation of administrative tasks.
- Studied the role of command-line tools in cloud system management.

**Results Achieved:**

Understood how AWS CLI can be applied to resource management and support administrative tasks on AWS more efficiently.

### Thursday – Learning about AWS CLI Security and Weekly Review

**Activities Performed:**
- Studied the relationship between AWS CLI and AWS IAM in access control.
- Explored the roles of IAM Users, IAM Roles, and Policies when performing operations through AWS CLI.
- Learned basic security principles for protecting credentials used to access AWS CLI.
- Reviewed the knowledge gained about AWS CLI and its applications in AWS resource management.

**Results Achieved:**

Understood the relationship between AWS CLI and IAM in access management and recognized the importance of protecting credentials when using command-line tools.
