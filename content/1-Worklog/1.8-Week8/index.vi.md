
# BÁO CÁO TIẾN ĐỘ HỌC TẬP

**Lĩnh vực: AWS Cloud Security**

## TUẦN 8 – Tìm hiểu AWS CLI và quản lý tài nguyên AWS bằng dòng lệnh

### Thứ 2 – Tìm hiểu tổng quan về AWS CLI

**Nội dung thực hiện:**
- Tìm hiểu khái niệm và vai trò của AWS Command Line Interface (AWS CLI).
- Nghiên cứu cách AWS CLI hỗ trợ tương tác với các dịch vụ AWS thông qua dòng lệnh.
- Tìm hiểu sự khác biệt giữa việc quản lý tài nguyên thông qua AWS Management Console và AWS CLI.
- Tìm hiểu các trường hợp sử dụng phổ biến của AWS CLI.

**Kết quả đạt được:**

Hiểu được chức năng của AWS CLI và vai trò của công cụ này trong việc hỗ trợ quản lý, tương tác với các dịch vụ AWS thông qua dòng lệnh.

### Thứ 3 – Tìm hiểu cách sử dụng AWS CLI

**Nội dung thực hiện:**
- Tìm hiểu cấu trúc cơ bản của một câu lệnh AWS CLI.
- Nghiên cứu cách sử dụng các lệnh để truy vấn thông tin dịch vụ AWS.
- Tìm hiểu các tham số và tùy chọn thường được sử dụng trong câu lệnh.
- Thực hành một số lệnh cơ bản để làm quen với AWS CLI.

**Kết quả đạt được:**

Nắm được cấu trúc cơ bản của câu lệnh AWS CLI và biết cách sử dụng các lệnh để tương tác, truy vấn thông tin từ các dịch vụ AWS.

### Thứ 4 – Tìm hiểu ứng dụng AWS CLI trong quản lý tài nguyên

**Nội dung thực hiện:**
- Tìm hiểu cách sử dụng AWS CLI để quản lý và kiểm tra tài nguyên AWS.
- Nghiên cứu cách truy vấn thông tin về các dịch vụ như EC2 và S3.
- Tìm hiểu cách sử dụng AWS CLI để hỗ trợ tự động hóa các thao tác quản trị.
- Nghiên cứu vai trò của dòng lệnh trong việc quản lý hệ thống Cloud.

**Kết quả đạt được:**

Hiểu được khả năng ứng dụng AWS CLI trong quản lý tài nguyên và hỗ trợ thực hiện các thao tác quản trị trên AWS một cách thuận tiện hơn.

### Thứ 5 – Tìm hiểu bảo mật và tổng kết về AWS CLI

**Nội dung thực hiện:**
- Tìm hiểu mối liên hệ giữa AWS CLI và AWS IAM trong việc kiểm soát quyền truy cập.
- Nghiên cứu vai trò của IAM User, IAM Role và Policy khi thực hiện các thao tác thông qua AWS CLI.
- Tìm hiểu các nguyên tắc bảo mật khi sử dụng thông tin xác thực để truy cập AWS CLI.
- Tổng hợp kiến thức về AWS CLI và các ứng dụng trong quản lý tài nguyên AWS.

**Kết quả đạt được:**

Hiểu được mối liên hệ giữa AWS CLI và IAM trong việc quản lý quyền truy cập, đồng thời nhận thức được tầm quan trọng của việc bảo vệ thông tin xác thực khi sử dụng công cụ dòng lệnh.
