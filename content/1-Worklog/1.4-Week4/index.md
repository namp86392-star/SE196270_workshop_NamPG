# LEARNING PROGRESS REPORT

**Field: AWS Cloud Security**

## WEEK 4 – Learning about Amazon EC2 and Server Security on AWS

### Monday – Introduction to Amazon EC2

**Activities Performed:**
- Learned about the concept and role of Amazon Elastic Compute Cloud (EC2).
- Studied the basic components of an EC2 Instance.
- Explored different Instance Types and how to select suitable configurations based on usage requirements.
- Studied the relationship between EC2 and network components in VPC.

**Results Achieved:**

Understood the functions of Amazon EC2 and how to deploy virtual servers on AWS, as well as the basic components of an EC2 Instance.

### Tuesday – Learning about EC2 Instance Deployment

**Activities Performed:**
- Learned how to launch and configure an EC2 Instance.
- Studied the role of Amazon Machine Image (AMI).
- Explored how to select Instance Types, Key Pairs, and Network Settings.
- Observed the operating status and basic configuration details of an EC2 Instance.

**Results Achieved:**

Understood the process of deploying an EC2 Instance and the role of different configuration components during server deployment on AWS.

### Wednesday – Learning about EC2 Security and Access Control

**Activities Performed:**
- Learned how to use Security Groups to control traffic to EC2 Instances.
- Studied different methods of connecting to and managing EC2 Instances.
- Explored the role of Key Pairs in connection authentication.
- Studied basic security principles for deploying and managing cloud servers.

**Results Achieved:**

Understood the basic security mechanisms of EC2, particularly network access control and authentication when connecting to servers.

### Thursday – Learning about IAM Roles for EC2

**Activities Performed:**
- Learned about the concept and role of IAM Roles for EC2 Instances.
- Studied how IAM Roles allow EC2 to access other AWS services.
- Explored the differences between using IAM Users and IAM Roles for access management.
- Studied how to attach IAM Roles to EC2 Instances to reduce the need for directly using credentials.

**Results Achieved:**

Understood how IAM Roles help manage EC2 access to other AWS services and recognized the importance of secure credential management.
